# B2B Sales Pipeline & Win-Loss Analytics

A recruiter-ready SQL and Power BI portfolio project that answers one practical leadership question:

> Where is the sales pipeline leaking, which segments convert best, and what should the business change?

[View the delivery roadmap](https://github.com/users/RamyaSrikari/projects/3)

## Why this project

This project demonstrates advanced SQL in a domain where business context matters: B2B sales, RevOps, and go-to-market analytics. It uses synthetic data only—no employer, client, or proprietary information.

## Questions the analysis will answer

- What are the stage-by-stage funnel conversion rates?
- Which lead sources, regions, industries, and deal sizes win most often?
- Where do opportunities stall or drop?
- Which segments and sales representatives close fastest?
- What are the dominant win and loss reasons?
- How are win rate, pipeline value, and sales-cycle length changing over time?

## Planned technical work

- CTEs for a multi-stage funnel
- Window functions for ranking, rolling win rates, and velocity
- Conditional aggregation for segment and win-loss analysis
- Cohort-style lead-source analysis
- BigQuery as the analytical warehouse
- Power BI for the decision-facing dashboard
